## What this assignment will cover

A prediction without an uncertainty estimate is not a scientific result, and a
model nobody can interrogate is hard to trust. This assignment covers both.

You will take a model you built earlier in the course and:

- Produce calibrated uncertainty estimates for its predictions
- Check whether those estimates are actually calibrated, rather than assuming it
- Identify which features drive the model's predictions, and how
- Examine whether the model relies on anything physically implausible
- Write a short assessment of whether you would trust this model's output in a
  decision-making context, and what would have to be true for that trust to be
  warranted
