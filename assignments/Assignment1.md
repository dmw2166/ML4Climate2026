## What this assignment will cover

This first assignment checks that everyone starts the course on the same footing
with the tools we will use every week, and sets up the repository you will submit
all later work to.

You will:

- Confirm your Python environment works and the packages we need are installed
- Work through a short review of the Python you will need: arrays, indexing,
  plotting, and reading tabular data
- Practice the Unix/Linux commands used to move around a filesystem and run scripts
- Create a **private** GitHub repository named `ml4climate2026`, add the instructor
  as a collaborator, and push a first commit
- Confirm you can open, run, and save a Jupyter notebook

## Prerequisites

CLMT5053 or CLMT5405. No machine learning background assumed.
